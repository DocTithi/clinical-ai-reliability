# Security Policy

## Supported versions

The project is pre-1.0 research software. Security fixes target the latest release.

## Reporting

Please report security issues privately to the repository owner using GitHub's private vulnerability reporting feature when available.

Do not open a public issue containing patient data, secrets, API keys, credentials, or exploitable details.

## Clinical and privacy note

CAR is not a substitute for a healthcare organization's security, privacy, clinical safety, or regulatory processes.

The default provenance layer hashes raw input and output instead of copying them into the envelope. Hashing alone is not anonymization.
